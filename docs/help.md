# TaskHub help

Quick reference for the task management demo and suggested prompts for the AI assistant.

## Suggested prompts

- "Summarize my task overview"
- "Show me pending tasks"
- "What is overdue?"

## Areas

- **Dashboard** (`/`) — status counts and recent tasks
- **Tasks** (`/tasks`) — filter by status, priority, assignee, and due date; select tasks and set one status
- **Task detail** (`/tasks/$taskId`) — view one task
